# Sahayak (ClassOS)

Hackathon project: a syllabus-grounded learning platform for K-12 schools. Teachers upload class material, AI generates reviewable practice content with source citations, and students get a tutor grounded strictly in approved syllabus material.

Full blueprint: [docs/product-overview.md](docs/product-overview.md)

## Structure

- `src/` – source code
- `docs/` – documentation
- `tests/` – tests
